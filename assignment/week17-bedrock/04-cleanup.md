# 마무리 · 결과 보관과 전용 자원 정리

필요한 결과를 보관하고 실행 중인 수집 작업이 없는지 확인한다. 이 패키지는 자동 삭제를 수행하지 않는다.

```text
python -m lab.cli plan
```

출력한 본인 계정·suffix의 자원 이름을 대조한 뒤 콘솔에서 정리한다.

1. 전용 Knowledge Base의 데이터 소스 삭제 정책을 확인한다. 수집 작업 중이면 상태를 먼저 확인한다.
2. 실습 데이터 소스와 KB를 삭제한다. DELETE 정책은 연결한 인덱스의 수집 데이터에 영향을 줄 수 있어 공유 인덱스에 적용하지 않는다.
3. 본인 S3 Vectors 버킷의 `documents` 인덱스를 삭제하고 벡터 버킷을 삭제한다.
4. 일반 S3 버킷의 `docs/` 아래 TXT와 metadata를 정리한 뒤 빈 버킷을 삭제한다. 별도로 버전 관리를 켰다면 이전 버전과 삭제 마커도 확인한다.
5. 다른 서비스에서 사용하지 않는 실습용 `KeulkeulBedrockKB-suffix` 역할의 전용 인라인 정책과 역할을 삭제한다.
6. 이번 실습용 고객 관리형 정책 01~04는 관리자가 연결 해제·정리한다. 공용 로그인 정책이나 다른 과제의 정책을 임의로 삭제하지 않는다.
7. 남은 자원과 사용량·청구를 확인한다. 청구 반영에는 지연이 있을 수 있다.

삭제 권한이 없으면 자원 이름과 오류를 관리자에게 전달한다. 자동으로 모든 자원이 삭제됐다고 가정하지 않는다. 재실습은 새 폴더·새 suffix를 사용하거나 진행자와 상태 파일을 검토한다.

[보고서](templates/report.md)에는 모델 호출의 실제 usage·stopReason, Sync·검색 원문, 생성 입력에 추가된 근거, top-k 변경 관찰, 권한·비용 이해와 자원 정리를 기록한다. 결과가 같거나 개선되지 않았어도 그대로 설명한다.

비밀키·토큰·개인 설정·계정 전체 정보·로그인 캐시는 제출하지 않는다. 가상 연습 문서와 필요한 원문 발췌를 사용하며 개인 문서를 공유하지 않는다.
