클라우드 실습 운영 안내
이 문서는 Amazon Bedrock 실습을 위한 가상 연습 자료입니다. 실제 동아리의 일정이나 규정이 아닙니다.

1. 실습 식별 정보
이번 가상 실습의 이름은 CloudShelf입니다. 실습 코드는 CLOUD-RAG-27입니다. 참가자는 질문에 문서의 실습 이름을 함께 적어 다른 프로젝트의 안내와 혼동하지 않습니다. 이 코드는 연습용 식별 정보이며 AWS 계정이나 로그인 자격 증명이 아닙니다.

2. 진행 일정
CloudShelf 연습에서는 수요일 오후 7시 30분에 문서 검색 실습을 시작합니다. 보고서 제출 마감은 금요일 오후 9시 10분입니다. 보고서는 실습 포털의 bedrock-foundations 폴더에 제출합니다. 실제 동아리의 포털 주소나 개인 이메일은 이 자료에 포함하지 않습니다.

3. 실습 환경
원본 문서와 Knowledge Base, 벡터 인덱스의 기준 리전은 서울 ap-northeast-2입니다. 생성 모델의 교차 리전 추론을 사용하는 경우 실제 처리 리전은 별도 확인합니다. 이번 문서는 운영 중인 고객 데이터가 아니라 학습용으로 작성한 텍스트입니다.

4. 제출물
보고서에는 모델 직접 호출의 응답과 토큰 사용량, 검색된 원문, 검색 근거를 전달한 답변을 기록합니다. 정답 근거가 어디에 있는지 자신의 말로 설명하고 문서에 없는 정보에 모델이 어떻게 답했는지도 적습니다. 화면 캡처에는 액세스 키, 토큰과 개인 계정 설정을 포함하지 않습니다.

5. 결과 확인
실습 코드를 묻는 질문은 첫 번째 절에서 확인하고, 마감과 제출 경로를 묻는 질문은 두 번째 절에서 확인합니다. 이 문서에는 가상 동아리의 회비나 회장 연락처가 없습니다. 모르는 정보를 묻는 질문에 대해서는 문서에 적힌 내용과 적히지 않은 내용을 구분해야 합니다.

6. 문서 변경 연습
진행자가 문서 업데이트를 안내하면 첫 번째 절의 실습 코드만 변경합니다. 코드를 변경한 뒤에는 원본 문서를 다시 업로드하고 데이터 소스를 동기화합니다. 문서에 기록하는 연습 코드와 실제 AWS 자원 이름은 서로 다른 값입니다.

7. 저장과 정리
문서는 실습용 일반 S3 버킷의 docs 경로에 저장합니다. TXT와 같은 이름에 metadata.json을 붙인 파일도 함께 업로드합니다. 실습 후에는 안내에 따라 전용 Knowledge Base, 벡터 인덱스와 버킷, 원본 S3, 서비스 역할을 각각 확인합니다. 다른 프로젝트와 공유하는 자원은 이 실습의 정리 대상이 아닙니다.
