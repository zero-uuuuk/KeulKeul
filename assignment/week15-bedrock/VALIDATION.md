# 제작·검증 범위

확인일: 2026-11-02.

## 로컬에서 확인한 내용

- Windows Python 3.11에서 AWS를 호출하지 않는 테스트 18개 통과.
- 실제 Botocore 요청 스키마로 Converse·Retrieve·S3 업로드 인자 검증.
- KB 없이 모델 직접 호출 경로, 실제 응답 필드 usage·stopReason 전달 확인.
- 출력 상한만 바꿀 때 나머지 생성 요청 유지, 직접 호출/RAG의 같은 system prompt 사용 확인.
- 검색 원문이 실제 생성 입력에 포함되는지, 빈 검색 시 생성을 생략하는지 확인.
- doc_id 검사·중복 제거·조각 수/길이 상한·존재하지 않는 근거 번호 감지 확인.
- 잘못된 계정·루트 신원 차단, 공유 버킷 임의 지정 차단, 정책별 길이와 docs/ 범위 확인.
- CreateIndex 권한을 인덱스 ARN에 부여하는 회귀 검사 추가. 이전 배포본에서 버킷 ARN에 묶여 있던 정책 오류를 수정했다.
- 업로드의 계정 소유자 지정, 실패 문서가 있는 Sync를 성공으로 처리하지 않는지 확인.
- 초기 설정과 계획 명령을 AWS 세션 생성이 금지된 상태에서 실행해 외부 호출이 없음을 확인.
- 별도 임시 폴더에서 CLI의 초기 설정·계획·KB 없는 generate·retrieve·rag 실행과 JSON 결과 저장을 가짜 클라이언트로 확인.
- Windows 설치 PowerShell 스크립트의 구문 확인.

테스트는 가짜 AWS 클라이언트와 응답을 사용한다. 테스트 출력의 업로드·생성 완료 문구가 실제 클라우드 실행을 뜻하지 않는다. 테스트의 숫자와 텍스트를 실습 결과로 제공하지 않는다.

## 실제 AWS에서 확인하지 않은 내용

- 실제 로그인과 IAM 정책 적용, 콘솔 UI 전체 단계와 추가 조회 권한
- 실계정 자원 생성·삭제, 모델 접근과 추론, 문서 수집·검색·동기화
- 응답 품질, 검색 조각 수, 모델 출력, 실행 시간과 비용
- Mac 설치·실행

배포 전 진행자는 INSTRUCTOR.md에 따라 처음부터 자원 정리까지 실계정 리허설을 수행하고 결과를 따로 기록한다. 로컬 테스트 통과가 실제 AWS 실습 완주를 보장하지 않는다.
