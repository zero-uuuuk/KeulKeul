## 스터디 소개

KeulKeul은 한양대학교 데이터사이언스학부 학생들이 함께 운영하는 클라우드 컴퓨팅 스터디입니다.

AI 서비스가 실제 사용자에게 안정적으로 제공되기 위해 필요한 배포, 확장, 저장소, 서버리스 아키텍처를 AWS 환경에서 직접 다룹니다. 모델 자체를 만드는 데서 끝나지 않고, 클라우드의 특성에 맞춰 서비스를 운영 가능한 형태로 배포하는 과정을 중심으로 학습합니다.

---

## 레포지토리 목적

이 레포지토리는 KeulKeul 스터디에서 진행한 AWS 실습 과제, 예제 코드, 실습 기록을 정리하는 공간입니다.

각 실습은 AWS 주요 서비스를 직접 연결해 보며, AI 서비스 배포에 필요한 인프라 구성과 서비스 운영 흐름을 익히는 데 초점을 둡니다.

## 실습 구성

```text
assignment
├── week1-auto-scaling-load-balancer
│   └── EC2, ALB, Auto Scaling Group 부하 테스트
├── week2-lambda
│   └── Lambda endpoint, S3 trigger, API Gateway, image classifier
├── week3-s3
│   └── Presigned URL, static website, S3 Vectors RAG, Route 53 domain
├── week4-dynamodb&rds
│   └── DynamoDB, RDS, Lambda DB 연결 실습
├── week5-serverless-architecture
│   └── AI model approval serverless architecture
├── week6-cloudwatch
│   └── CloudWatch Logs, Metrics, Alarm, Dashboard
└── week7-docker1
    └── Docker Image, Container, Dockerfile
```
